# 📁 File Manager

A small file-handling project built with **Python and Streamlit**.  
It provides a simple UI to perform common file operations inside a dedicated storage directory.

## ✨ Features

- ➕ **Create File** — Create a new empty file.
- ✍️ **Write File** — Write content to a file. If the file doesn't exist, it is created automatically.
- 📖 **Read File** — Read and display the contents of an existing file.
- 🔄 **Update File**
  - Rename a file
  - Add/append content
  - Overwrite existing content
- 🗑️ **Delete File** — Permanently delete a file.

## 🛠️ Tech Stack

- Python
- Streamlit
- pathlib
- datetime
